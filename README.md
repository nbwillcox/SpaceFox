# SpaceFox

A free, retro-flavored on-rails space shooter with neon-meets-painted art: pilot the Firebrand through canyons and fleets, dodge and shoot, and take on the Regent's Gloom Armada.

**Play it in your browser:** https://nbwillcox.github.io/SpaceFox/

Work in progress (milestone 1: flight slice). See `DESIGN.md` for the full plan.

## Controls

| Action | Keys |
| --- | --- |
| Steer | `W A S D` or the arrow keys |
| Fire | `Space` (hold) |
| Barrel roll | `Q` / `E`, or double-tap left / right |
| Boost / brake | `Shift` / `Ctrl` |
| Bomb | `B` |
| Pause | `P` or `Esc` |

All of these can be changed in **Settings > Key bindings**.

### On a phone or tablet

Play in landscape. A floating stick on the left steers the ship; on the right, **FIRE** (hold) shoots, the two **ROLL** buttons barrel-roll left or right to deflect shots, and **BOOST**, **BRAKE** and **BOMB** sit above them. The pause button opens the menu. The on-screen controls appear on touch devices automatically; Settings has size, opacity and a left-handed layout. Use your browser's *Add to Home Screen* to install it as a full-screen app.
